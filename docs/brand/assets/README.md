# Know the Map logo assets

Use `ktm-lockup-horizontal-primary.svg` on light surfaces and `ktm-lockup-horizontal-reverse.svg` on dark surfaces. Use SVG whenever possible; PNG files are convenience exports.

## Recommended files

- Web navigation: `ktm-lockup-horizontal-primary.svg`
- Dark footer/hero: `ktm-lockup-horizontal-reverse.svg`
- GitHub README: `ktm-readme-banner.svg` or `.png`
- Social link preview: `ktm-social-card.png` (1200 x 630)
- Social profile: `ktm-social-avatar.png` (1200 x 1200)
- Browser: `ktm-favicon.svg` plus PNG/ICO fallbacks

## Core colors

- Deep Ink `#0B1F2A`
- Paper `#F5F1E8`
- Mineral `#2F7F78`
- Signal `#C7F23D`

Keep the Signal color to one meaningful node or route segment. Full rules are in the brand manual.
